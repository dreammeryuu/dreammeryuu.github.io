Jarvis privacy policy · 隐私政策

Last updated: October 17, 2026

Who uses Jarvis

Jarvis is a private, single-user voice assistant. Its only user is its owner, who runs it on his own computers. It is not offered to anyone else.

What Google data it accesses

With the owner's consent, Jarvis requests read-only access to his Gmail (gmail.readonly) and Google Calendar (calendar.readonly). It reads message senders, subjects, snippets and, when asked, message text; and calendar events. It never sends, changes or deletes email or events.

How the data is used

Only to answer the owner's own questions (for example a morning summary of today's events and important unread email). Data is processed on the owner's computers. When a question needs it, the few relevant snippets may be sent to the Anthropic Claude API to compose the answer. Google user data is not sold, not used for advertising, not shared with anyone else, and not used to train AI models.

Jarvis's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and removal

Access credentials are stored in the Windows Credential Manager on the owner's computer. Access can be revoked at any time at myaccount.google.com/permissions.
